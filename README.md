# Jupyter Environment & NumPy Foundations

Week 05 Monday kata — Jupyter notebook setup, core NumPy operations, and notebook best practices.

## What's Inside

`week5-mon-kata.ipynb` covers:

- **Part A:** Jupyter basics — markdown/code cells, the hidden-state bug and how to fix it
- **Part B:** NumPy — array creation, vectorized speed advantage, 2D indexing, boolean masking, broadcasting, axis aggregation, reshape view-vs-copy
- **Part C:** In-notebook documentation lookup, assembled deliverable

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install jupyterlab numpy
jupyter lab
```

Open `week5-mon-kata.ipynb` and run **Kernel → Restart Kernel and Run All Cells** to verify.

## Requirements

- Python 3.10+
- JupyterLab
- NumPy 2.2+
